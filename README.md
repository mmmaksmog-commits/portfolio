## Особенности

- Без фреймворков: HTML, CSS и JavaScript-модули
- Все тексты, контакты и проекты лежат в одном файле, [`js/config.js`](js/config.js)
- Форма заявок отправляет письмо на почту через [FormSubmit](https://formsubmit.co), без своего сервера. Если отправка не удалась, предлагается отправить заявку в WhatsApp
- Ссылки на WhatsApp и звонок, мобильное меню, подсветка активного раздела
- Адаптивная вёрстка от 320 px до широких экранов
